## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13 standard library + PIL) draws the 1024×1024
front page deterministically — two runs write byte-identical output —
and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`),
as a JPEG under 1 MiB.

- Lead story (Shenzhen summit) in the biggest slot at the top
- The other 14 stories in a two-column grid, each with its own
  programmatic illustration and a `Source: …` line beneath it
